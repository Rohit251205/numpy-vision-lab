# NumPy Vision Lab

## Overview

NumPy Vision Lab is a beginner-friendly image processing project built using NumPy and Pillow. It demonstrates how NumPy arrays can be used to perform common image processing operations without relying on advanced computer vision libraries.

---

## Technologies Used

- Python
- NumPy
- Pillow
- Git
- GitHub
- VS Code

---

## Features

### Image Processing

- Image Loading
- NumPy Array Conversion
- Image Information

### Basic Operations

- Horizontal Flip
- Vertical Flip
- Rotate 90°
- Center Crop

### Color Transformations

- Grayscale
- Negative
- Brightness Adjustment

### Image Analytics

- Minimum Pixel Value
- Maximum Pixel Value
- Mean Pixel Value
- Median Pixel Value
- Standard Deviation
- Variance
